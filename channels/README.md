# Channel skills

One skill per channel, each with its own rules and its own taste.json, all built on ghost-editor:

- `founder-reels/`: the founder's interview reels.
- `hpf-reels/`: HPF workout / form-correction videos.

Install (next to ghost-editor in the skills folder):

    cp -r ~/.claude/skills/ghost-editor/channels/founder-reels ~/.claude/skills/
    cp -r ~/.claude/skills/ghost-editor/channels/hpf-reels ~/.claude/skills/
